# Mind Map Video Maker

## GitHub Pages पर चलाएँ
1. GitHub में New repository बनाएँ।
2. इस फ़ोल्डर की `index.html` फ़ाइल repository में upload करें।
3. Repository → Settings → Pages खोलें।
4. Deploy from a branch चुनें; Branch `main`, folder `/ (root)` चुनकर Save करें।
5. कुछ मिनट बाद GitHub Pages URL पर ऐप खुल जाएगा।

## फीचर्स
- शाखाओं का टेक्स्ट, रंग और क्रम बदलें
- मोबाइल से फोटो अपलोड करें या image URL डालें
- 16:9 एनिमेटेड माइंड मैप प्रीव्यू
- PNG सेव और WebM वीडियो रिकॉर्डिंग

नोट: ब्राउज़र रिकॉर्डिंग WebM बनाती है। MP4 के लिए डाउनलोड की गई फ़ाइल CapCut में खोलकर MP4 Export करें। मोबाइल पर रिकॉर्डिंग के समय पेज खुला रखें।
